# Architecture decision records

One file per decision that someone could reasonably have made differently. Each
is written before the work it affects; dates are when it was decided.

## Template

```md
# NNNN. Title in a few words

- **Status:** Proposed | Accepted | Superseded by NNNN
- **Date:** YYYY-MM-DD
- **Decided by:** who made the call

## Context

What forces a decision, and the constraints that apply.

## Decision

What was chosen, stated plainly.

## Options considered

The alternatives and why they lost.

## Consequences

What gets easier, what gets harder, and what to watch.
```

Never rewrite an accepted decision. When it changes, add a new ADR and mark the
old one superseded.
