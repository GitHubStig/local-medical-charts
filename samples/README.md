# Sample reports

**Everything here is fictional** — every patient, lab, ID number and result.

These are merged reports in exactly the format `deno task ocr` produces,
generated by `deno task samples` (`scripts/generate-samples.ts`) from made-up
page transcriptions run through the real merge and analyte catalog.

- **Alex Tan** — four reports from two labs (Northside Pathology, then Harbour
  Medical Lab), which print test names, units, ranges and flags differently.
- **Sam Rivera** — a single report, for the one-report dashboard state.

Use them to try the app without real reports: `deno task dev` loads them into
the browser version automatically, and you can drop them into the desktop app's
import. Regenerate after changing the schema or the catalog.
